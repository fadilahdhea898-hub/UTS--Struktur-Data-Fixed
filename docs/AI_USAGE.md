# Declaration of AI Usage

Aplikasi dan dataset ini dikembangkan dengan bantuan AI Collaboration Tool (Gemini/ChatGPT) untuk:
1. Membantu struktur awal arsitektur folder proyek Maven.
2. Memverifikasi kelengkapan 16 atribut putusan dan data provenance.
3. Mengisi logika umum pengurutan Merge Sort pada Linked List.

Seluruh logika struktur data murni (`Node`, `SinglyLinkedList`, `Stack`) dipastikan memenuhi spesifikasi UTS tanpa mengimpor `java.util.ArrayList` atau `java.util.LinkedList`.
